# 🎧 Spotify -> Telegram Bio Live Sync

Служба автоматической синхронизации играющего трека из **Spotify** в описание профиля (**Bio**) вашего **Telegram**-аккаунта в реальном времени.

---

## ✨ Возможности
- **Нативное определение музыки (Windows Media API)**: отслеживает воспроизведение Spotify через системные события Windows (`winsdk`), без задержек и без обязательного использования API-токенов Spotify.
- **Работа в фоновом режиме (Трей)**: удобная иконка в системном трее Windows (`pystray`) с возможностью быстрого включения/паузы и выхода.
- **Автозапуск при старте Windows**: бесшумный запуск в фоновом режиме без появления черных консольных окон (`run_background.vbs`, `install_startup.ps1`).
- **Резервный статус**: при остановке или паузе музыки автоматически возвращается ваш стандартный статус из настроек.

## 🛠 Настройка (Шаг за шагом)

### Шаг 1. Получить Telegram API ключи
1. Перейдите на [my.telegram.org](https://my.telegram.org) и авторизуйтесь со своего аккаунта Telegram.
2. Откройте раздел **API development tools**.
3. Создайте приложение (название любое, например `SpotifyBioSync`).
4. Скопируйте значения `api_id` и `api_hash`.

### Шаг 2. Заполнить `.env`
1. Скопируйте файл `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   ```
2. Откройте `.env` и вставьте ваши ключи:
   ```env
   TG_API_ID=ваш_api_id
   TG_API_HASH=ваш_api_hash
   DEFAULT_BIO=Listening to Spotify • vibes
   ```

### Шаг 3. Первичная авторизация
Запустите файл **`auth_setup.bat`** (или выполните `python setup_session.py`).
Консоль запросит номер телефона и одноразовый код подтверждения из Telegram. После успешного входа сессия сохранится локально в файл `*.session`.

## 🚀 Запуск

### Запуск в системном трее
```bash
python service.py
```
В трее Windows появится иконка приложения.

### Автозапуск при включении Windows
Чтобы служба запускалась автоматически в фоне без всплывающих окон:
1. Запустите PowerShell.
2. Выполните команду:
   ```powershell
   powershell -ExecutionPolicy Bypass -File install_startup.ps1
   ```
*(Для отключения автозапуска запустите `uninstall_startup.ps1`)*.
